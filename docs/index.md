# SenangWebs Whiteboard (SWW)

A powerful, client-side JavaScript drawing library for creating interactive digital whiteboards and vector drawings with advanced performance optimizations and modern UI components.

## Features

- **Drawing Tools**: Basic shapes, lines, arrows, text, and media elements.
- **Advanced Capabilities**: Layer management, selection tools, undo/redo, and performance optimization.
- **Styling & Customization**: Custom themes, fill styles, and stroke customization.
- **User Interface**: Control panel, properties panel, and context menus.
- **Markdown Support**: Comprehensive parser with rich formatting options.
