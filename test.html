Context Menu Test

Test Instructions:

  1. Create some shapes using the toolbar
  2. Right-click on empty space to see the context menu
  3. Select elements and right-click to see context options
  4. Test Copy/Paste functionality
  5. Test Group/Ungroup with multiple selected elements

  • Properties panel hidden by default

  • Right-click shows context menu
  • Context menu items enabled/disabled appropriately
  • Copy/Paste works for duplicating elements
  • Group/Ungroup works with multiple selection
  • Edit option available only for text elements
